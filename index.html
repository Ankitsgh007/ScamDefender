How ScamDefender checks a website

The dashboard mirrors the detection concepts implemented in the extension.

🔗

Suspicious URL Detection

Flags IP-based URLs, selected risky TLDs and common look-alike spellings such as g00gle or paypa1.

🔒

HTTPS Verification

Checks whether the website is using HTTPS and reports a warning when the URL uses an insecure protocol.

🧠

Scam Content Scanner

Looks for scam phrases such as “Congratulations”, “Win iPhone”, “Claim Prize” and “Free Gift”.

🚨

Instant Warning

The extension can show a warning when one or more suspicious signals are detected on the current page.
